# 0003 — pnpm as the package manager

- **Status:** Accepted
- **Date:** 2026-11-11

## Context

The repo had no lockfile. The old prototypes contained both `package-lock.json` and `pnpm-lock.yaml`, which is ambiguous. A single package manager keeps installs reproducible and CI simple.

## Decision

Use pnpm (v10) and commit `pnpm-lock.yaml`. Do not add `package-lock.json`, `yarn.lock`, or `bun.lockb`.

## Consequences

- Install: `pnpm install`. Add: `pnpm add <pkg>`. Run scripts: `pnpm <script>`.
- CI and local machines must use the same pnpm major version.
